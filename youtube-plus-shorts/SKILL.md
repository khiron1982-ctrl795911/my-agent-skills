# YouTube + Shorts 同時生成スキル

## 概要
横型（YouTube 16:9）と縦型（YouTube Shorts 9:16）を同時に生成する。
声サンプル基準: `C:\Users\khiro\output\transcribe\voice_20260620\voice_cleaned_for_video.m4a`

## 実行手順

### Step 1: テーマ確認
- テーマ・ターゲット・尺（横型: 5〜15分想定 / 縦型: 60秒以内）を確認
- 未指定なら会話の流れから推定して進める

### Step 2: 台本作成（2本同時）
**横型台本**（YouTube長尺）:
- 構成: フック(30秒) → 本編 → CTA
- 話し方: 声サンプルのテンポ・間に合わせる

**縦型台本**（Shorts/Reels）:
- 構成: 最初の3秒でフック → 要点のみ → CTA
- 横型の要点を抽出して圧縮

### Step 3: Canva/Pikaで映像生成
- Pikaクレジットがある場合: generate_video（横型16:9 / 縦型9:16）
- クレジット不足の場合: Canvaで presentation（横型）+ your_story（縦型）を生成

### Step 4: 音声・字幕
- ナレーション: 声サンプル基準で整音
- 字幕: add_captions ツールで自動生成

### Step 5: 保存と投稿準備
- 生成した動画・サムネイルは必ず `C:\Users\khiro\OneDrive\Desktop\VIDEO\{テーマ名}\` にフォルダを作って保存する（VIDEO直下やデスクトップ直下にファイルを直接置かない）
- サムネイル生成（generate_image ツール、不可なら Pillow で作成。アップロード時のサムネイル設定は必須）
- タイトル・説明文・タグを生成し、動画と同じ場所にテキストで保存する

### Step 6: アップロード（必ず承認を取ってから）
- ここまで（ファイル生成・下書き作成）は自動でよいが、YouTubeへのアップロードは公開操作にあたるため、実行前に必ず「この内容でアップロードしてよいですか？」と確認する
- 承認が得られたら YouTube API 経由でアップロードし、サムネイルも忘れずに設定する
- 承認が得られない場合はファイルの場所を案内して止まる

## 出力物（3点セット）
1. 横型動画ファイル（16:9）
2. 縦型ショート動画ファイル（9:16）
3. サムネイル画像（横型用）

## 検証チェックリスト
□ 3点セット（横型・縦型・サムネイル）がすべて揃っているか
□ 保存先が `Desktop\VIDEO\{テーマ名}\` になっているか
□ サムネイルを作成したか（アップロード時の設定は必須）
□ タイトル・説明文・タグのテキストを動画と同じフォルダに保存したか
□ アップロードは承認を取ってから実行したか（無断アップロード禁止）

## 終了条件
3点セットを `Desktop\VIDEO\{テーマ名}\` に保存し、保存場所を報告したら一区切り。アップロードは承認があった場合のみ行う。
