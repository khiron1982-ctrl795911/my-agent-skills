# /neta-scout — ニュース収集×企画ネタ提案スキル

## 使い方
```
/neta-scout             # WATCH.md の担当領域すべてを収集
/neta-scout 宇宙        # テーマを指定して収集（何でもOK）
/neta-scout --sns       # SNS発信向けの企画角度だけに絞る
```

## このスキルがやること

### Step 1: 担当領域を読む
1. `~/kikaku/WATCH.md` を読み、ウォッチ対象テーマ・企画の出し先・除外条件を把握する
2. 引数でテーマが指定されていれば、そのテーマを優先する（WATCH.md の除外条件だけは常に適用）
3. `~/sns/BRAND_GUIDE.md` の「得意ネタ」「禁止表現」も確認し、企画角度がブランドとズレないようにする

### Step 2: ニュースを収集する（WebSearch）
1. テーマごとに WebSearch で **直近1週間** のニュースを検索する（「{テーマ} ニュース 2026年7月」のように時期を含める）
2. 各テーマ 3〜5 本、確度の高い情報源（公式発表・大手メディア）を優先して拾う
3. 噂・未確認リークは除外。日付と出典URLを必ず控える

### Step 3: レポートにまとめる
`~/kikaku/reports/YYYY-MM-DD_{テーマ略称}.md` として保存する。形式:

```
# YYYY-MM-DD 企画ネタレポート（{テーマ}）

## 今週のハイライト（3行）
- {今週いちばん大事な動きを3行で}

## ニュースと企画ネタ
### {ニュース見出し}
- **要約**: {2〜3行。専門用語にはひとこと説明を添える}
- **なぜ今**: {今週・来週に扱うべき理由。予定されているイベント・発表日があれば明記}
- **企画角度**:
  - Threads: {投稿の切り口1行}
  - ショート動画: {台本の切り口1行}
  - 本業（人事）: {あれば。なければ省略}
  - アフィリエイト: {~/sns/AFFILIATE.md のジャンルに合う書籍・ガジェット等が自然に紹介できる場合のみ。商品名と切り口を1行。無理にこじつけない。なければ省略}
- **出典**: [媒体名](URL)（YYYY-MM-DD）

## 来週の注目カレンダー
| 日付 | 予定 | 企画メモ |
|------|------|---------|

## 今週やるならこの1本
{最優先の企画を1つ選び、理由を2行で}
```

### Step 4: ビューアを更新する
```
cd ~/kikaku && python scripts/build_viewer.py
```
を実行し、`~/kikaku/index.html` を再生成する。

### Step 5: 結果を報告する
- 「今週やるならこの1本」と、レポート・ビューアのファイルパスを画面に出力して終わる
- 投稿文や動画の生成はしない。ユーザーが選んだネタを /sns-threads 等に渡すのは次の指示を待つ

## 検証チェックリスト
□ すべてのニュースに出典URLと日付があるか（憶測・記憶で書いていないか）
□ 直近1週間より古い話題を「今週の動き」として書いていないか
□ WATCH.md の除外条件（噂・政治宗教・情報商材系）に触れていないか
□ 専門用語にひとこと説明を添えたか（読者は非エンジニア）
□ ビューア（index.html）の再生成まで終えたか

## フィードバック反映（自動ブラッシュアップ用）
- 実行前に `~/.claude/projects/C--Users-khiro/memory/feedback_skills.md` があれば読み、このスキルへの過去の修正指示を反映する
- ユーザーから出力への修正指示を受けたら、同ファイルに「日付／スキル名／指示内容／今後どうするか」を1行で追記し、同じ指摘を二度受けないようにする

## 終了条件
レポート保存とビューア更新を終え、「今週やるならこの1本」を提示したら止まる。投稿・動画生成・送信は行わない。
