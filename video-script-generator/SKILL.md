# /video-script-generator — 動画台本テキスト生成スキル

## 使い方
```
/video-script-generator テーマ：面接で聞かれる逆質問対策（60秒ショート用）
/video-script-generator YouTube10分動画の台本を作って（テーマ：評価制度の作り方）
/video-script-generator この記事を元に台本化して
/video-script-generator 台本だけ欲しい。動画化は後で自分で頼む
```

## このスキルがやること
1. テーマ・尺（ショート60秒程度／YouTube本編数分〜10分程度）・伝えたい結論を確認する
2. 冒頭フック（最初の3〜5秒で離脱されない一言）を作る
3. 本編を「結論→理由→具体例→まとめ」など分かりやすい順に構成する
4. セリフ調（実際に話す言葉）で書く。ナレーション読み上げを想定し、一文を短く区切る
5. 尺の目安に合わせて文字数・秒数を調整する（1分＝日本語で概ね300文字前後を目安）
6. 台本テキストのみを出力する。動画ファイルが欲しい場合は `/video-pipeline`（横型）または `/short-video`（縦型ショート）、両方欲しい場合は `/youtube-plus-shorts` の利用を案内する

## 出力フォーマット
```markdown
# 動画台本 — テーマ：{テーマ}（想定尺：{秒数/分数}）

## フック（冒頭0〜5秒）
{セリフ}

## 本編
### 導入
{セリフ}

### 本論1：{見出し}
{セリフ}

### 本論2：{見出し}
{セリフ}

### まとめ
{セリフ}

## CTA（締めの一言）
{セリフ}

---
想定文字数: {N}文字（目安秒数：約{秒}秒）
動画ファイルが必要な場合: 横型は /video-pipeline、縦型ショートは /short-video、両方は /youtube-plus-shorts をご利用ください
[下書き - 要確認]
```

## 検証チェックリスト
```
□ フックが冒頭3〜5秒で離脱を防げる内容か
□ セリフ調で書けているか（読み上げやすい短文になっているか）
□ 想定尺に対して文字数が合っているか（長すぎ・短すぎないか）
□ CTAが入っているか
□ 動画ファイル生成が必要な場合、適切な動画生成スキルを案内したか
```

## 終了条件
台本テキストを出力したら止まる（動画ファイルの生成は行わない）。
「台本を作成しました。動画にする場合は /video-pipeline か /short-video をお使いください」と報告する。
