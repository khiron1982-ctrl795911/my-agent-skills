# PowerPoint整形スキル

## 目的
雑多なテキストを「1スライド1メッセージ」の構成に変換する。出力は2モード：
- **モードA（デフォルト）**: テキスト形式のスライド構成案（PowerPointに手貼り用）
- **モードB**: .pptx 実ファイル生成（「ファイルで」「pptxで」と言われた場合。**必ず `C:\\Users\\kuwata\\.claude\\skills\\pptx-simul\\SKILL.md` を先に読むこと**）

## ワークフロー

### STEP 1 — 目的と聞き手を判定
| 判定 | 選択肢 |
|---|---|
| 目的 | 報告 / 提案 / 整理 / 稟議説明 |
| 聞き手 | 役員 / 部門長 / 実務者 / 社外 |
| 制約 | 枚数指定・時間指定があれば優先 |

**役員向けは必ず「結論→根拠→依頼事項」の順。** 経緯から始めない。

### STEP 2 — 構成テンプレートを選択
1. **概要整理型**: 結論 → 要点 → 補足
2. **進捗報告型**: サマリー → 成果 → 課題 → 次アクション（期限・担当付き）
3. **問題整理型**: 現状 → 原因 → 対策 → 実行計画
4. **提案・稟議型**: 背景 → 課題 → 提案 → 効果（定量）→ コスト → リスクと対策 → 依頼事項
5. **比較検討型**: 選定基準 → 選択肢比較表 → 推奨案 → 理由

### STEP 3 — スライド化ルール
- 1スライド1テーマ、タイトルは**メッセージ型**（「現状分析」ではなく「離職率は正社員で悪化、原因は評価不満」）
- 箇条書きは3〜5行、1行30文字以内
- 数値は必ず比較対象付き（昨対・目標比・業界平均）
- 抽象語（「強化する」「推進する」）は具体アクションに置換
- 最終スライドに「依頼事項 / Next Action（担当・期限）」を必ず置く

### STEP 4 — 出力形式（モードA）
```
■スライド1：{メッセージ型タイトル}
・要点1
・要点2
【備考】グラフ推奨：{棒/折れ線/表} — {理由}
```
各スライドに「入れるべきグラフ・表」の推奨を付ける。

## セルフチェック（出力前）
- [ ] タイトルを読むだけでストーリーが通るか（タイトルだけ縦読みテスト）
- [ ] 数字に比較対象があるか
- [ ] 最終スライドにNext Actionがあるか
- [ ] 1行30文字を超えていないか
- [ ] 入力にない事実・数値を創作していないか

## HIRO固有の頻出パターン
- 稟議系（Benefit Station、社保外部委託など）→ テンプレ4を使用し「承認者が聞きそうな質問と回答」スライドを提案する
- 人事制度改定系 → G1-G4等級・デュアルトラック構造の用語を正確に使う（hr-dashboardスキル参照）
