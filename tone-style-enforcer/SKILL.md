# /tone-style-enforcer — 文体・トーン統一スキル

## 使い方
```
/tone-style-enforcer この文章を~/sns/BRAND_GUIDE.md の文体に合わせて直して（本文貼り付け）
/tone-style-enforcer サンプル文章を基準に、この原稿のトーンを揃えて
/tone-style-enforcer 敬語を統一して、もっとカジュアルにして
/tone-style-enforcer 差分だけ見せて（修正案チェック用）
```

## このスキルがやること
1. 基準となる文体を確認する（`~/sns/BRAND_GUIDE.md`、指定されたサンプル文章、または「もっとカジュアルに」等の直接指示）
2. 渡された文章を読み、一人称・語尾・敬語レベル・禁止表現・絵文字の使い方などのズレを洗い出す
3. 基準に合わせて文章を書き直す（意味・数字・固有名詞は変えない）
4. 修正前→修正後の差分を箇所ごとに示す
5. 直した理由（どの基準に沿ったか）を一言添える
6. 全体を通して基準に合っているか、最終チェックリストで確認する

## 出力フォーマット
```markdown
# 文体チェック結果

## 基準
{使用した基準：BRAND_GUIDE.md / サンプル文章 / 直接指示の内容}

## 修正箇所
1. 修正前：「{元の表現}」
   修正後：「{直した表現}」
   理由：{一言（例：一人称をガイドに合わせた）}

2. 修正前：「{元の表現}」
   修正後：「{直した表現}」
   理由：{一言}

## 修正後の全文
{修正後の本文全体}

---
[下書き - 要確認]
```

## 検証チェックリスト
```
□ 基準（BRAND_GUIDE.md/サンプル/指示）を確認してから直したか
□ 意味・数字・固有名詞を変えていないか
□ 一人称・語尾・敬語レベルが基準と揃っているか
□ 禁止表現（BRAND_GUIDE.mdにあれば）が残っていないか
□ 修正箇所ごとに理由を添えたか
```

## 終了条件
差分と修正後の全文を出力したら止まる。
「文体を基準に合わせて修正しました。差分を確認してください」と報告する。
