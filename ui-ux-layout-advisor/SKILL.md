# /ui-ux-layout-advisor — レイアウト改善アドバイザー

## 使い方
```
/ui-ux-layout-advisor この採用管理画面のスクリーンショットを見て改善点を教えて
/ui-ux-layout-advisor 評価シートのExcelレイアウトが見にくいので直したい
/ui-ux-layout-advisor この社内ポータルのトップページ、情報が多すぎて分かりにくい
/ui-ux-layout-advisor このPowerPointスライドの配置、もっと見やすくできる？
```

## このスキルがやること
1. 対象（画像・スクリーンショット・貼り付けられたレイアウト説明）を確認する。新しい図面や画面そのものは作らず、あくまで「今あるもの」への助言に徹する
2. 情報の優先順位（何を一番先に見てほしいか）が視覚的に伝わっているかを確認する
3. 余白・整列・グルーピング・文字の大きさのバランスを点検する
4. 色づかいやコントラストが読みやすいか、情報が詰め込みすぎていないかを点検する
5. 「良い点」「気になる点」「具体的な改善案」の3つに分けて、専門用語を使わず平易にまとめる
6. 改善案は優先度（すぐ直せる／時間をかけて直す）を付けて提示する

## 出力フォーマット
```markdown
# レイアウト改善レポート：{対象名（例：中途採用選考シートのExcelレイアウト）}

## 良い点
- （例）必要な項目が一通り揃っており、抜け漏れがない

## 気になる点
- （例）項目同士の余白が狭く、どこからどこまでが1人分のデータか分かりにくい
- （例）重要な「合否」欄が右端に埋もれていて目立たない

## 改善案（優先度つき）
【すぐ直せる】
- 「合否」欄を先頭列に移動し、色分け（合格＝緑、見送り＝グレーなど）を付ける
- 行と行の間に薄い罫線を入れて、1人分の区切りを分かりやすくする

【時間をかけて直す】
- 項目数が多い場合はタブや別シートに分けて、1画面あたりの情報量を減らす

[助言 - 要確認：実際のレイアウト変更は元ファイルを直接編集してください。このスキルは提案のみ行います]
```

## 検証チェックリスト
- □ 新しい図・画面を作ってしまっていないか（助言のみに徹しているか）
- □ 「良い点」を必ず1つ以上挙げているか（ダメ出しだけになっていないか）
- □ 改善案が抽象論（「見やすくしましょう」等）で終わっていないか、具体的な操作に落とし込めているか
- □ 優先度（すぐ直せる／時間をかける）を分けて示しているか
- □ 専門用語（ヒエラルキー、コントラスト比など）をそのまま使わず言い換えているか
- □ 対象ファイルを勝手に上書き・変更していないか

## 終了条件
改善レポートを1セット提示したら完成として提示し、「他に気になる箇所はないか」を確認して止まる。
