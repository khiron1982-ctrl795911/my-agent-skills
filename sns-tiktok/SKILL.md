# /sns-tiktok — TikTok運用一気通貫スキル

## 使い方
```
/sns-tiktok                       # リサーチ→企画5案→1案に絞って台本下書きまで
/sns-tiktok テーマ：人事のリアル   # ジャンル指定で実行
/sns-tiktok --企画だけ            # 企画案5本の提案まで
/sns-tiktok --台本だけ 企画名     # 決まった企画の台本のみ
/sns-tiktok --分析                # 投稿済み動画の数値を貼り付けて分析
```

## 大前提（絶対厳守）
- **自動投稿はしない。** TikTokは自動投稿が規約違反・アカウント停止リスクになるため、このスキルは**下書き（台本＋動画素材＋キャプション）まで**しか作らない。投稿は必ずユーザー自身が行う
- 初回実行時に「目的（何を売る/何のための認知か）・ターゲット・投稿頻度」が未設定なら、先にそこを質問して `~/sns/TIKTOK_GUIDE.md` に書き残す（ここがズレると後工程が全部ズレるため）

## このスキルがやること

### Step 1: 前提読み込み
1. `~/sns/TIKTOK_GUIDE.md`（なければ作成を提案）と `~/sns/BRAND_GUIDE.md` を読む
2. `~/.claude/projects/C--Users-khiro/memory/feedback_sns.md` の蓄積ルールを反映する

### Step 2: リサーチ（3つの視点を分けて行う）
1. **トレンド**: いま伸びている音源・形式・話題（Web検索）
2. **競合・お手本**: 同ジャンルで伸びている動画の構造（フック・展開・長さ）を分解
3. **規約・アルゴリズム**: 規約違反にならないか、後述のKPIを満たす設計か

### Step 3: 企画（ここで8割決まる）
1. リサーチを元に企画案を5本出す
2. 各案を「視聴者メリット／完了率が出そうか／規約リスク／導線／差別化」の5つの目で採点する（チェック役として厳しめに）
3. 最高得点の1案を推奨として提示する（採点表も見せる）

### Step 4: 台本
- 構成: 【冒頭2秒フック】→【本編（1メッセージ）】→【CTA】
- 冒頭2秒で「続きを見る理由」を作る（疑問・数字・意外性）
- 長さ: 30〜45秒目安（日本語150〜220文字程度）
- 禁止表現（「絶対」「100%」「必ず稼げる」等）を避ける

### Step 5: 下書き保存
`~/sns/_drafts/tiktok/YYYY-MM-DD_N.md` に保存:
```markdown
# TikTok下書き — {YYYY-MM-DD} #{N}

## 企画名・狙い
{企画名}／{狙い一言}

## 台本
【冒頭2秒フック】{セリフ}
【本編】{セリフ}
【CTA】{セリフ}

## キャプション＋ハッシュタグ（3〜5個）
{テキスト}

---
想定尺: {秒}秒／採点: {N}点
生成日時: {YYYY-MM-DD HH:MM}
[下書き - 要確認]
```

### Step 6: 動画化の案内（このスキルでは作らない）
動画ファイルが必要なら台本を `/short-video`（縦型1080×1920、保存先 Desktop\VIDEO）に渡す。

### 分析モード（--分析）
TikTokアプリのインサイト数値（貼り付けまたはスクリーンショット）を受け取り、KPIと比較:
| 指標 | 合格ライン |
|---|---|
| 冒頭2秒の継続率 | 50%以上 |
| 視聴維持率（平均再生時間÷尺） | 20%以上 |
| フル視聴率 | 10%以上 |
分析結果と「次に試す型」を feedback_sns.md に追記し、次回の企画に反映する。

## 検証チェックリスト
□ 冒頭2秒に離脱を止めるフックがあるか
□ 1動画1メッセージになっているか（詰め込みすぎない）
□ 禁止表現・規約リスク（医療・金融の断定、誇大広告等）がないか
□ 「[下書き - 要確認]」を付けたか
□ 自動投稿をしていないか（下書きまでで止めたか）
□ 採点表を提示したか（企画モード時）

## /loop との組み合わせ方
```
/loop 今日のTikTok企画と台本を/sns-tiktokで1本下書きして_drafts/tiktok/に保存されたら止まって
```
