# SIMUL PPTX 作成・修正ルール + 視覚QA

## 役割分担（他スキルとの関係）

- **見せ方・構成の相談**（「どう見せればいい」「レイアウト案を出して」）→ 先に `ppt-design-patterns` でパターンを決める
- **メモから章立て・スライド主張を作る** → 先に `powerpoint-corrections` で構成案を作る
- **作成・修正・QAの実装**（このスキル）→ パターン決定後にここのルールで実装する
- 重い視覚QAループはサブエージェント `pptx-qa` に委譲してメインの文脈を守る

## 作業の基本フロー（毎回この順で）

1. **原本をコピーして作業する**（`Desktop\人事フォルダ` 等の原本は上書き・削除しない）。
   修正版はバージョン番号を上げたファイル名で同フォルダに保存する。
2. 作業スクリプト・中間PNG・検証txtは `C:\Users\kuwata\work\pptx-tools\` に作る
   （ホーム直下や原本フォルダに作業ファイルを撒かない）。
3. python-pptx で修正 →「python-pptx の注意点」を確認。
4. **COMレンダリングで視覚QA**（座標QAだけでは崩れを見逃す。修正後は必須）。
5. 完成チェックリストで最終確認 → ユーザーに修正版パスと変更点を報告。

## フォントサイズ規則（絶対遵守）

| 用途 | 最小サイズ |
|---|---|
| 本文・箇条書き | 18pt 以上 |
| 小見出し・ラベル | 21pt 推奨 |
| 注釈・フッター・ブランディング | 14pt 以上（未満禁止） |
| タイトル | 28〜36pt |
| 数字・KPI | 24pt 以上 |

- `run.font.size = None`（継承）の場合も **18pt を明示設定**する
- フォント縮小で解決しない。入らないならスライドを分割する

## はみ出し・余白規則

- スライド端から **5% のマージン**を確保
- shape の left / top / right / bottom を **4辺すべてチェック**
- テキストボックスのみ対象（画像・グループ・OLE は width/height を変更しない）
- はみ出し修正は「縮小」ではなく「高さ拡張・位置移動」優先
- オーバーフロー検出は「1段落=1行」前提では不正確。**word wrap を考慮**すること
  （実際の折り返し行数 ≒ ceil(文字列総幅 ÷ ボックス幅)）
- 日本語の折り返しは単語境界を無視する → 長文は句読点・中黒位置で手動 `\n` 改行
  （「個人評価係数」等の複合語が途中で切れる事故が頻発）

## 情報量制限（1スライド）

メッセージ1つ / 箇条書き最大5 / 1行40文字以内推奨 / 表は5行×5列まで / グラフ1つ。
情報過多はスライド分割（圧縮・縮小は禁止）。

## デザイン原則

- 視認性 > デザイン性（3秒で理解できること優先）
- 結論を最も目立つ位置に。色数は最大3色。薄いグレー文字・細線は禁止

## 視覚QA: PowerPoint COM レンダリング（修正後は必須）

このPCは LibreOffice なし・**pywin32 + PowerPoint COM でPNG出力が動く**。
座標QAだけでは崩れを見逃すため、PPTX修正後は必ずPNG化して目視確認する。

```python
import win32com.client
app = win32com.client.Dispatch("PowerPoint.Application")
p = app.Presentations.Open(path, ReadOnly=True, WithWindow=False)
p.Slides(n).Export(abs_path_png, "PNG", 1600, 900)
p.Close()
# 並行プロセスとPowerPointを共用するため、作業途中で app.Quit() を呼ばない（最後に1回だけ）
```

- PNG出力先は `work\pptx-tools\qa_png\` などにまとめる（原本フォルダに出さない）
- QAループ: PNG出力 → Read で目視 → 問題列挙 → python-pptx で修正 → 再レンダリング。
  修正対象スライドが多い場合はサブエージェント `pptx-qa` に委譲し、
  プロンプトに「COMレンダリング→Readで目視→修正」のループを必ず入れる
- 対象ファイルをPowerPointで開いたまま実行すると開けない/PermissionError になる

## python-pptx の注意点

- フォントサイズは `a:rPr/@sz`（1/100pt単位）。`run.font.size` はEMU（÷12700でpt）
- スライドサイズ変更時は `a:xfrm` off/ext・フォント・`a:ln/@w`（線幅EMU）・`bodyPr` inset を**すべて同倍率**で
- 枠線除去は `noFill`+`w=0` では不十分。**solidFill子要素を全削除**してから noFill を追加。
  `<a:solidFill/>` **空タグ（色指定なし）** がテーマ色で線を描画するため、色付き狙い撃ちでは残る
- マスター/レイアウトは `master.shapes` が空のことがある → XML直接操作
- 手組み表には**空テキスト行・h=0.01"の極細区切り線・重複幽霊シェイプ**が埋まっていることがある。
  間延びの原因はほぼこれ
- 過去の一括修正スクリプト（fix_pptx_v2/v20〜v22等）は削除済み。必要なら本スキルの知見から再生成する
