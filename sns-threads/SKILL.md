# /sns-threads — Threads投稿下書き生成スキル

## 使い方
```
/sns-threads                          # 今日の投稿3本を下書き生成
/sns-threads 5                        # 今日の投稿5本を下書き生成
/sns-threads テーマ：AI副業の始め方   # テーマ指定で生成
/sns-threads --連投                   # 連投セット（3〜5本つなぎ）を生成
/sns-threads --pr                     # アフィリエイトPR投稿を1本生成
```

## このスキルがやること
1. `~/sns/BRAND_GUIDE.md` と `~/sns/CLAUDE.md` を読み込む
2. `~/.claude/projects/C--Users-khiro/memory/feedback_sns.md` のフィードバックを確認
3. 指定本数のThreads投稿下書きを生成する
4. 各投稿を検証する（文字数・文体・禁止表現・CTA）
5. `~/sns/_drafts/threads/YYYY-MM-DD_N.md` に保存する
6. 「下書きを保存しました。確認してください」と報告して止まる

## アフィリエイトPR投稿（--pr または自動混在）
- ルールの原本は `~/sns/AFFILIATE.md`。生成前に必ず読むこと
- **自動混在**: 通常の3本以上の生成時、`~/sns/_drafts/threads/`（archive含む）と `~/sns/_drafts/x/` の直近7日の `_PR` 付きファイルを合算して2本未満なら、うち1本をPR投稿にする。2本あれば混ぜない（週2本上限はThreads・X合算）
- PR投稿の追加ルール:
  - 冒頭付近に「#PR」を必ず入れる（ステマ規制対応。省略・末尾隠しは不可）
  - 商品は AFFILIATE.md のジャンル内から選び、「実際に使ってみた／読んでみた」体験談の型で書く
  - 本文にはリンクを直接書かず、本文かコメント欄想定で `{楽天リンクをここに貼る}` プレースホルダを置く
  - CTAは「1件目のコメントを見てもらう」を基本にする（本文に「プロフィールのリンクから」とは書かない。プロフィールのリンク置き場ができるまでの運用）
  - ファイル名は `YYYY-MM-DD_N_PR.md` とする

## 生成ルール（必ず守ること）

### フォーマット
- 1投稿: 最大500文字（必ず自分でカウントして確認）
- 連投セット: 3〜5本、各投稿が単体で読めるように書く
- 末尾CTA: BRAND_GUIDE.md のCTA定型文から選ぶ

### 検証チェックリスト（全て◯になるまで修正する）
```
□ 文字数が500文字以内か
□ BRAND_GUIDE.md の文体・一人称と合っているか
□ 禁止表現（「絶対」「100%」「必ず稼げる」等）が含まれていないか
□ CTAが入っているか
□ 最初の1〜2行でスクロールを止めるフックになっているか
□ 「[下書き - 要確認]」が末尾に付いているか
□ （PR投稿のみ）「#PR」が冒頭付近にあるか
□ （PR投稿のみ）`{楽天リンクをここに貼る}` プレースホルダがあるか
□ （PR投稿のみ）効果の断定ではなく実体験ベースの表現になっているか
```

### 保存フォーマット（Markdownファイル）
```markdown
# Threads下書き — {YYYY-MM-DD} #{N}

{投稿テキスト本文}

---
文字数: {N}文字
テーマ: {テーマ}
CTA: {使用したCTA}
生成日時: {YYYY-MM-DD HH:MM}

[下書き - 要確認]
```

## /loop との組み合わせ方
```
/loop 今日のThreads投稿3本を/sns-threadsで下書き生成して_drafts/threads/に保存されたら止まって
```

## 終了条件
指定本数のファイルが `~/sns/_drafts/threads/` に保存されたら必ず止まる。
「〇本の下書きを保存しました。`sns/_drafts/threads/` を確認してください。」と報告する。
