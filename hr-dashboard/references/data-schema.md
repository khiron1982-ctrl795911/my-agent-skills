# Excel データスキーマ詳細

## 全社員リスト — 月次シート（例: 2026年5月）

`pd.read_excel(xl, sheet_name='YYYY年M月', header=16)` で読み込む

### 主要列定義

| 列名 | 内容 | 備考 |
|---|---|---|
| 社員番号 | 従業員ID（数値） | 数値変換できないもの（役員行等）は除外 |
| (氏名) | 氏名 | |
| 勤務状態 | '休職中' / NaN | 休職者フィルタに使用 |
| 雇用形態 | '正社員' / '嘱託社員' / '契約社員(無期)' / 'シニアアルバイト' / '一般アルバイト' | |
| 勤続年数 | 数値（年） | 小数あり |
| 役職 | 'GM' / 'マネージャー' / 'チームリーダー' / '-' / 0 | '-' と 整数0 が混在 |
| 役割 | 'GM' / 'マネージャー' / 'チームリーダー' / 'シニアエキスパート' / 'エキスパート' / '一般社員' / 0（整数） | **0は整数** |
| 2026G等級 | 'G1-1'〜'G1-7' / 'G2-1'〜'G2-6' / 'G3-1'〜'G3-5' / 'G4-1'〜'G4-4' / '-' | 非正規は'-' |
| (所属コード) | 部署コード | |
| (所属名1) | 部署名（最上位） | 主要部署識別に使用 |
| (所属名2) | 課名 | 経理課の識別に使用 |
| (所属名3) | チーム名 | |
| (メール) | メールアドレス | |
| (性別) | '男' / '女' | |
| (入社日) | datetime | |
| (生年月日) | datetime | |
| (年齢) | 数値（整数） | |
| (退職日) | datetime | 在職中はNaT |
| (勤続年数) | '10年3ヵ月' 形式の文字列 | 数値の勤続年数列（col index 8）とは別 |

### 役割=0 の詳細
- 整数 `0` として格納（文字列'0'ではない）
- 該当者: 一般アルバイト13名、契約社員(無期)5名、シニアアルバイト4名、嘱託1名
- G等級: 全員'-'（等級なし）
- 役職: 整数0 または '-'
- 集計時は `'役割なし'` としてグループ化

## 残業・有給ファイル — 基準越えシート

`pd.read_excel(ot_xl, sheet_name='基準越え', header=None)`

- 実データ開始: 行6（0-indexed: 6）
- col0: 区分（一般社員等）
- col1: 部署名
- col2: 課名
- col3: 社員番号
- col4: 氏名
- col5: 100時間超カウント
- col6: 89時間超カウント
- col7: 45時間超カウント
- col8: TTL合計

### 45時間超人数の部署別集計
```python
df_ot = pd.read_excel(ot_xl, sheet_name='基準越え', header=None)
# 実データ行（氏名が存在する行のみ）
ot_data = df_ot[df_ot.iloc[:, 4].notna() & (df_ot.iloc[:, 4] != '')].copy()
ot_data.columns = ['区分','部署','課','社員番号','氏名','100h','89h','45h','TTL'] + list(range(9, df_ot.shape[1]))
ot_45 = ot_data[ot_data['45h'] >= 1].groupby('部署').size()
```

## 残業・有給ファイル — 有休シート

`pd.read_excel(ot_xl, sheet_name='有休', header=None)`

- 行3: ヘッダー（部, 課, NaN, 4月, 5月, ...）
- col1: 部（大分類）
- col2: 課
- col4: 4月取得日数（日/人平均）
- col5: 5月, col6: 6月 ... 以降月次

```python
df_leave = pd.read_excel(ot_xl, sheet_name='有休', header=None)
leave_data = df_leave.iloc[4:, [1, 2, 4]].copy()  # 4月分
leave_data.columns = ['部', '課', '4月']
leave_data['部'] = leave_data['部'].ffill()
leave_data = leave_data[leave_data['課'].notna()]
# 部単位で平均取得日数を集計
dept_leave = leave_data.groupby('部')['4月'].mean()
```
