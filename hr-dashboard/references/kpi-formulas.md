# KPI 計算式・定義集

## 管理職の定義

```
管理職（狭義）= GM + マネージャー  →  27名（10.0%）  ← 経営層報告・ISO30414に使用
管理職（広義）= GM + マネージャー + チームリーダー  →  58名（21.4%）
```

**⚠️ 重要**: 役職列（GM/マネージャー/チームリーダー/0/-）ではなく
**役割列** を使って集計する。役割列のほうが正確。

## 離職率の計算式

```
離職率（%) = 退職者数 ÷ (退職者数 + 現在の在籍数) × 100
```

- 分母 = 退職者数 + 在籍数（=期末在籍数の近似）
- 退職者一覧は2025年度（2025/4〜2026/3）の1年分を使用
- 月次離職率 = 当月退職数 ÷ 月初社員数 × 100

## 管理職女性比率の計算式

```
管理職女性比率(%) = 管理職の女性数 ÷ 管理職の総数 × 100
管理職 = GM + マネージャー（27名）
```

## 休職率

```
休職率(%) = 休職者数 ÷ 在籍総数 × 100
（勤務状態 == '休職中' の人数を使用）
```

## 退職者平均勤続年数

```
退職者平均勤続年数（全）= 全退職者の勤続年数（col9 = 数値）の平均
退職者平均勤続年数（正）= 雇用形態=='正社員' の退職者のみで平均
```

**注意**: 勤続年数は整数（年単位）。小数の場合もある。
退職者一覧 col34 の '1年5ヵ月' 形式ではなく col9 の数値を使う。
