# /workflow-automation-agent — 作業手順の分解・自動化設計スキル

## 使い方
```
/workflow-automation-agent 毎月の勤怠集計を楽にしたい
/workflow-automation-agent 新入社員の受け入れ準備の流れを整理して
/workflow-automation-agent この作業、自動化できる部分だけ教えて
/workflow-automation-agent 週次レポート作成の手順書を作って
```

## このスキルがやること
1. やりたいこと（ゴール）を一文で確認する。曖昧な場合は先に確認する
2. ゴールを、実行できる単位の手順（ステップ）に分解する
3. 各ステップについて「人がやる部分」と「AIやツールに任せられる部分」を仕分ける
4. 任せられる部分には、使えるツール・スキル・コマンドを具体的に当てはめる
5. 手順全体を通したときに、無駄な繰り返しや抜けがないか見直す
6. 定期実行にしたい場合は `/schedule` や `/loop` の利用を案内する（実際の予約設定はこのスキルでは行わない）

## 出力フォーマット
```
【ゴール】
（一文で）

【手順】
Step 1: （やること）
  担当: 人／AI・ツール
  使うもの: （具体的なツール名・スキル名・コマンド）
  注意点: （ミスしやすい点、確認が必要な点）

Step 2: ...
Step 3: ...

【自動化できる部分まとめ】
- （ステップ番号）: （どう自動化できるか、何を使うか）

【人の判断が必要な部分まとめ】
- （ステップ番号）: （なぜ人の確認が必要か）

【次にやること】
（定期実行にする場合は /schedule または /loop を案内。承認が必要な操作があれば明記）
```

## 検証チェックリスト
□ ゴールが一文で明確になっているか（曖昧なまま手順化していないか）
□ 各ステップが「何を入力に、何を出力するか」まで具体的か（「〜を分析する」のような曖昧な表現になっていないか）
□ 人の確認・承認が必要な箇所（公開・送信・課金・削除など）を自動化側に含めていないか
□ 使うツール・スキル名が実在し、このセットアップ内で使えるものか
□ 手順の順番に抜けや矛盾がないか
□ 定期実行が必要な場合、実際の予約設定は /schedule や /loop に委ねているか

## 終了条件
手順の分解と自動化できる部分の整理を報告したら終了。実際の自動化の実装・予約設定は行わず、必要なら次のアクション（該当スキル）を案内するところまでで止まる。
