# /onchain-transaction-analyzer — 暗号資産取引の解説スキル

## 使い方
```
/onchain-transaction-analyzer 0x1234...abcd という取引を説明して
/onchain-transaction-analyzer このウォレットアドレスの動きを見てほしい
/onchain-transaction-analyzer このスクリーンショットの取引、何をしているか教えて
/onchain-transaction-analyzer --初心者向け     # 専門用語をより丁寧に言い換える
```

## このスキルがやること
1. 対象の取引情報（アドレス・取引ID・スクリーンショット等）を確認する
2. 誰から誰に、何が、どれだけ動いたかを時系列で整理する
3. 出てきた専門用語（ウォレット、コントラクト、ガス代など）に、必ずその場で一言注釈をつける
4. 不審な点（見慣れないやり取り、極端に高い手数料、詐欺でよくあるパターンなど）がないか確認する
5. 全体の流れを、平易な日本語で要約する
6. 判断が難しい場合や金額が大きい場合は「専門家に確認することを推奨」と明記する

## 専門用語の言い換えルール（必ず守ること）
初出時は必ず「用語（一言説明）」の形で書く。例:
```
- ウォレット（暗号資産を保管する電子的な財布のようなもの）
- コントラクト（あらかじめ決められた条件で自動的に処理を行うプログラム）
- ガス代（取引を処理してもらうために支払う手数料）
- トークン（そのネットワーク上でやり取りされるデジタルな資産の単位）
- アドレス（銀行の口座番号にあたる、送金先・送金元を示す文字列）
```

## 出力フォーマット
```
【取引の概要】
いつ: ...
誰から誰へ: ...（アドレスは省略せず記載し、初出のウォレット・コントラクトには注釈）
何が動いたか: ...（通貨の種類・数量）
手数料（ガス代）: ...

【時系列の流れ】
1. ...
2. ...
3. ...

【気になる点】
（不審な点があれば具体的に。なければ「特に不審な点は見当たりません」と明記）

【まとめ（専門用語なし）】
（小学生にも伝わるレベルの平易な日本語で3行程度に要約）

【注意】
本スキルは取引内容の説明のみを行います。実際の送金・取引操作は行いません。
金額が大きい取引や判断に迷う内容は、専門家（取引所のサポート等）への確認をおすすめします。
```

## 検証チェックリスト
□ 専門用語がすべて初出時に平易な言い換え付きで説明されているか
□ アドレスや金額など、数値情報を憶測で埋めていないか（分からない部分は「不明」と明記したか）
□ 不審な点の有無を必ず明言しているか（無言で済ませていないか）
□ 実際の送金・取引・承認操作を勝手に実行していないか（分析・説明のみに留めているか）
□ まとめ部分が専門用語なしで読めるレベルになっているか
□ 金額が大きい・判断が難しい場合に専門家への確認を促す一文を入れたか

## 終了条件
取引内容の解説と気になる点の報告を終えたら終了。実際の送金・承認・課金操作は行わず、必要であればユーザー自身の判断・実行に委ねる。
