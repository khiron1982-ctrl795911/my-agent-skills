# ビジネスメール整形スキル

## 目的
HIROが貼り付けたラフな文章を、**件名込みで即送信できる**ビジネスメールに変換する。

## ワークフロー

### STEP 1 — 3つの要素を判定する（不明なら1回だけ質問）
| 判定項目 | 選択肢 | デフォルト |
|---|---|---|
| 宛先 | 社内（上司/他部署/部下）/ 社外（取引先/官公庁/応募者） | 文脈から推定 |
| 目的 | 依頼 / 報告 / 謝罪 / 催促 / 御礼 / 回答 / 案内 | 文脈から推定 |
| 温度感 | 通常 / やや丁重 / 最丁重（謝罪・官公庁向け） | 通常 |

**注意：** 労働局・年金事務所・監査法人など官公庁/士業宛は自動的に「最丁重」を適用。

### STEP 2 — 変換ルール
- **件名**を必ず生成する（【】書き＋用件＋会社名/氏名。例：`【ご確認のお願い】賞与支給に関する社会保険手続きについて`）
- 構成：宛名 → 挨拶 → 用件（結論先出し）→ 詳細 → 依頼事項と期限 → 結び → 署名欄プレースホルダ
- 依頼には**期限と対応方法を明示**（「○月○日（○）までに、本メールへのご返信にて」）
- 二重敬語・過剰なクッション言葉は削る（「させていただく」の乱用禁止）
- 原文にない事実を**勝手に追加しない**。不足情報は `【要記入：○○】` でプレースホルダ化
- 添付に言及がある場合は「添付ファイルのご確認」を本文に含める

### STEP 3 — 出力形式
1. **完成メール**（件名＋本文）をコードブロックで出力（コピペ用）
2. 直下に「調整ポイント」を2〜3行（例：もっと柔らかくする場合の代替表現）
3. 謝罪・催促など高リスク文面の場合のみ、トーン違いの第2案を併記

## パターン別の型

### 催促（角を立てない）
行き違いのお詫び → 前回送付日と内容の再掲 → 期限の再提示 → 「ご状況をお聞かせいただけますと幸いです」

### 謝罪
事実の認識 → 明確な謝罪（言い訳を先に書かない）→ 原因 → 再発防止 → 改めての謝罪

### 官公庁・監査対応
「ご査収」「ご高配」等の格式語を使用。断定を避けたい箇所は「〜と認識しております」を使う。

## セルフチェック（出力前に必ず確認）
- [ ] 件名だけで用件がわかるか
- [ ] 依頼に期限があるか
- [ ] 原文にない事実を創作していないか
- [ ] 固有名詞・日付・金額が原文と一致しているか
- [ ] 「させていただく」が3回以上出ていないか
