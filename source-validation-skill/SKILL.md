# /source-validation-skill — 情報源の信頼性チェックスキル

## 使い方
```
/source-validation-skill このURLの情報は信頼できる？
/source-validation-skill この記事の出典と発行日を確認して
/source-validation-skill 集めた3つの情報源を信頼度順に並べて
/source-validation-skill このSNS投稿の内容、裏付けが取れるか調べて
```

## このスキルがやること
1. 対象の情報源（URL・記事・投稿など）を特定する
2. Web検索が使える場合は、実際に発行元サイト・一次情報・複数の報道を検索して裏付けを確認する（推測で済ませない）
3. 発行元（誰が書いたか・組織か個人か）を確認する
4. 発行日・更新日を確認し、情報が古くなっていないかを見る
5. 主張の裏付け（一次情報・データの出典・他媒体での言及）があるかを確認する
6. 偏り（特定の立場からの意見か、広告・宣伝目的かなど）がないかを確認する
7. 下記フォーマットで信頼度を整理して提示する（断定しすぎず「現時点でわかる範囲」として示す）

## 出力フォーマット
```markdown
## チェック対象
{URLまたは情報源の名称}

## 確認結果
- 発行元: {組織名／個人名、わかる範囲で}
- 発行日・更新日: {日付、不明な場合は「確認できず」}
- 裏付け状況: {一次情報あり／他媒体でも報道あり／裏付け見つからず、など}
- 偏りの可能性: {あり（理由）／特になし}

## 信頼度の目安
{高い／中くらい／低い／判断保留} — {理由を1〜2文で}

## 補足・注意点
{使う際に気をつけたほうがよい点があれば}
```

## 検証チェックリスト
```
□ Web検索が使える環境では、実際に検索して発行元・日付を確認したか（推測で書いていないか）
□ 発行元が個人か組織か、専門性があるかを確認したか
□ 発行日が古い場合、その旨を明記したか
□ 主張の裏付け（一次情報・データ元）の有無を確認したか
□ 「信頼できる／できない」を断定しすぎず、根拠とともに「現時点での目安」として示しているか
□ 専門用語（一次情報、エビデンスレベル等）に平易な説明を添えているか
```

## 終了条件
信頼度の目安と根拠を提示したら一区切りとする。追加の情報源チェックが必要であればユーザーからの指示を待つ。
