# 人事メールテンプレート集

`{ }` は差し込み箇所。埋められない場合は【要確認】を付けてユーザーに示す。
署名はユーザーのGmail署名に任せる（本文には入れない）。

## A1. 勤怠打刻の修正依頼（本人宛・社内）

件名: 【依頼】{YYYY年M月}分 勤怠打刻のご確認・修正のお願い

```
{名前}さん

お疲れ様です。人事の桑田です。

{YYYY年M月}分の勤怠を確認したところ、以下の日に打刻の記録がありませんでした。

{対象日付リスト（例: ・2/2(月)、2/3(火) … 出勤打刻なし）}

お手数ですが、{期限日}までに勤怠システムから打刻修正の申請をお願いします。
在宅・直行直帰などで打刻不要の日があれば、その旨ご返信ください。

給与計算の締めがありますので、期限までのご対応をお願いいたします。
ご不明点があればお気軽にご連絡ください。
```
