# /hook-generator — 冒頭フック案10本生成スキル

## 使い方
```
/hook-generator テーマ：転職で失敗しない面接対策
/hook-generator この文章の冒頭フックを10個考えて（本文貼り付け）
/hook-generator 数字系のフックだけ5個ちょうだい
/hook-generator Threads用に短めのフック案を出して
```

## このスキルがやること
1. テーマまたは貼り付けられた本文から、伝えたい核心（読み手が得する情報・驚き）を抽出する
2. 下記のバリエーション軸をできるだけ幅広く使い、フック案を10本作る
3. 媒体の指定があれば文字数・トーンを合わせる（Threads/Instagramは短め、YouTubeは動画の最初の5秒を想定）
4. 誇張・断定しすぎる禁止表現（「絶対」「100%」「必ず」等）を避ける
5. 10本を一覧で出力し、どの軸を使ったかを併記する

## フックのバリエーション軸（案出しに必ず複数使うこと）
- **疑問形**：「なぜ◯◯な人は△△なのか？」
- **数字**：「3つのポイント」「たった5分で」「9割の人が知らない」
- **逆説・意外性**：「実は◯◯しない方がいい」「常識と逆」
- **体験談・失敗談**：「私は◯◯で大失敗した」
- **警告・損失回避**：「知らないと損する」「これをやると評価が下がる」
- **共感・あるある**：「こんな経験ありませんか」
- **断定・言い切り**：「結論、◯◯です」
- **会話の切り取り**：「上司にこう言われた」


## 検証チェックリスト
```
□ 10本作ったか（重複や似すぎた案がないか）
□ バリエーション軸を4種類以上使っているか
□ 誇張・断定しすぎる禁止表現が入っていないか
□ 媒体指定がある場合、文字数・トーンが合っているか
□ おすすめ上位を選んで理由を添えたか
```

## 終了条件
フック案10本（指定があればその本数）を出力したら止まる。
「フック案10本を出しました。気に入ったものがあれば番号で教えてください」と報告する。
