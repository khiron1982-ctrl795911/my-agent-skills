# /sns-draft — 下書き管理・レビュースキル

## 使い方
```
/sns-draft                    # 全媒体の未確認下書きを一覧表示
/sns-draft threads            # Threads下書きのみ表示
/sns-draft instagram          # Instagram下書きのみ表示
/sns-draft tiktok             # TikTok下書きのみ表示
/sns-draft check 2026-06-28   # 指定日の下書きを全文表示・チェック
/sns-draft approve threads 1  # 指定ファイルを「確認済み」に更新
/sns-draft clean              # 7日以上前の下書きをアーカイブ
```

## このスキルがやること

### 一覧表示モード（引数なし or 媒体名）
1. `~/sns/_drafts/{媒体}/` を走査する
2. 「[下書き - 要確認]」が含まれるファイルを未確認として抽出
3. 日付・媒体・文字数・先頭30文字をテーブル表示
4. 「確認が必要なファイル: N件」と報告して止まる

### チェックモード（check YYYY-MM-DD）
1. 指定日の全下書きを全文表示
2. 各ファイルに対してチェックリストを実行
3. 問題があれば修正案を提示（修正するか聞いてから行動）

### 承認モード（approve）
1. 指定ファイルの `[下書き - 要確認]` を `[確認済み - {YYYY-MM-DD HH:MM}]` に置換
2. 「承認しました。投稿する場合はスクリプトを実行してください」と案内

### クリーンアップモード（clean）
1. 作成から7日以上経過した下書きを `_drafts/archive/` に移動
2. 移動したファイル数を報告

## 表示フォーマット
```
【未確認下書き一覧】2026-06-28 確認

媒体         ファイル                      文字数   プレビュー
------------ ----------------------------- -------- ----------------------
Threads      2026-06-28_1.md               245      AI副業を始めて3ヶ月...
Threads      2026-06-28_2.md               312      多くの人が誤解してる...
Instagram    2026-06-28_1.md               128      【リール台本】冒頭3秒...

合計: 3件 / 未確認: 3件
```

## /loop との組み合わせ方
```
/loop _drafts/に溜まった下書きの一覧を/sns-draftで確認して未確認件数を教えて
```

## 検証チェックリスト
□ 未確認（[下書き - 要確認]付き）のファイルを漏れなく拾えているか
□ 承認時、置換後のマークに日時が入っているか
□ アーカイブ移動の前に、対象ファイルの一覧をユーザーに見せたか（無断で移動しない）
□ 実際の投稿（公開操作）はこのスキルでは行っていないか

## 終了条件
