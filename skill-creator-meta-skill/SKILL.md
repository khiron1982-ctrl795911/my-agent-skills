# /skill-creator-meta-skill — スキルたたき台生成スキル

## 使い方
```
/skill-creator-meta-skill 議事録を整形するスキルが欲しい
/skill-creator-meta-skill name: expense-checker で経費チェック用のスキルを作って
/skill-creator-meta-skill 既存の sns-threads と同じ書式で名刺管理スキルを作って
```

補足: これは「たたき台をすぐ作る」簡易版です。作った後に本格的な精度チューニングやテスト（評価実行）が必要な場合は、組み込みの `skill-creator` を使ってください。

## このスキルがやること
1. 作りたいスキルの目的・使う場面をユーザーに確認する（曖昧なら質問する）
2. スキル名（name）を英小文字・ハイフン区切りで決める
3. 紛らわしい既存スキルがないか確認し、description の「Use when」「Do NOT use for」を書き分ける
4. 下記テンプレートに沿ってSKILL.mdの本文（使い方・手順・出力フォーマット・チェックリスト・終了条件）を作成する
5. 保存先のパス（例: `~/.claude/skills/<name>/SKILL.md`）を確認してから保存する
6. 「たたき台を保存しました。内容を確認してください」と報告して止まる

## 検証チェックリスト
□ name が既存スキルと重複していないか
□ description に「Use when」「Do NOT use for」が両方入っているか
□ 紛らわしい隣接スキルとの違いが具体的に書かれているか（スキル名を挙げて区別しているか）
□ 本文が60〜90行程度に収まっているか（冗長になっていないか）
□ 出力フォーマットが「実際にそのまま使えるテンプレート」になっているか（抽象的な説明で終わっていないか）
□ 保存先パスをユーザーに確認してから書き込んだか

## 終了条件
SKILL.mdのたたき台を指定パスに保存し、内容確認を促したら終了。実際にこのスキルを他の場所（例: ~/.claude/skills/）へコピー・登録する作業は、ユーザーの指示を受けてから行う。
