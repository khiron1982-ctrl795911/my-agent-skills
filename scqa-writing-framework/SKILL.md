# /scqa-writing-framework — SCQA構成の説明文生成スキル

## 使い方
```
/scqa-writing-framework テーマ：残業時間削減の提案（本文貼り付け）
/scqa-writing-framework このメモをSCQAで報告文にして
/scqa-writing-framework 上司向けの説明資料をSCQAで整理して
/scqa-writing-framework 記事用にSCQAで書き直して
```

## このスキルがやること
1. 元ネタ（メモ・箇条書き・貼り付け文章）から、状況・問題・結論を洗い出す
2. Situation→Complication→Question→Answerの順に文章を割り振る
3. 各段落を簡潔にまとめ、専門用語は平易な言葉に言い換える
4. 段落間のつながりが自然になるよう接続表現を整える
5. 完成文と、どの段落がSCQAのどれに当たるかの対応表を出力する

## SCQAの4要素（日本語での考え方と例）

### S：Situation（状況）
- 今の状態・前提を、読み手と共有できる形で簡潔に示す
- 例：「現在、当社の平均残業時間は月20時間で、前年から横ばいです。」

### C：Complication（問題提起）
- 状況の中にある「引っかかり」「このままではまずい点」を示し、興味を引く
- 例：「しかし来月から一部部署で人員が減り、業務量は変わらない見込みです。」

### Q：Question（問い）
- 読み手が自然に抱く疑問を、代弁する形で言語化する
- 例：「では、人員が減っても残業を増やさずに業務を回すにはどうすればよいか。」

### A：Answer（答え）
- 問いに対する結論・提案を、具体的かつ行動につながる形で示す
- 例：「業務の一部を外部委託し、当月中に引き継ぎ手順を整備することを提案します。」

## 出力フォーマット
```markdown
# SCQA構成文章 — テーマ：{テーマ}

## S（状況）
{本文}

## C（問題提起）
{本文}

## Q（問い）
{本文}

## A（答え）
{本文}

---
文字数: {N}文字
[下書き - 要確認]
```

## 検証チェックリスト
```
□ S/C/Q/Aの4段が全て入っているか（省略していないか）
□ Cで「引っかかり」がきちんと伝わるか
□ Qが読み手の自然な疑問になっているか
□ Aが具体的で行動につながる内容か
□ 専門用語を平易な言葉に言い換えたか
```

## 終了条件
SCQA4段構成の完成文を出力したら止まる。
「SCQAの4段構成で作成しました。内容を確認してください」と報告する。
