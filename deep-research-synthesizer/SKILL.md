# /deep-research-synthesizer — 複数資料の統合分析スキル

## 使い方
```
/deep-research-synthesizer この5本の記事から共通する傾向を教えて
/deep-research-synthesizer 3社のアンケート結果をまとめて、共通する課題を出して
/deep-research-synthesizer このリサーチ資料群から、人事施策に使える示唆を抽出して
/deep-research-synthesizer 集めた情報を統合して、次にとるべきアクションを提案して
```

## このスキルがやること
1. 対象となる複数の資料（記事・データ・議事録など）を読み込み、それぞれの要点を把握する
2. 資料をまたいで繰り返し出てくるテーマ・共通パターンを見つける
3. 逆に資料間で意見や結果が食い違っている点（矛盾・対立）を洗い出す
4. 単なる要約ではなく「だからどうするべきか」という示唆（インサイト）に変換する
5. 情報量が多い場合は、重要度の低い内容を削り、実務に使える部分だけを残す
6. 下記フォーマットで、根拠となった資料を明記しながら整理する

## 出力フォーマット
```markdown
## 分析対象
- 資料1: {タイトル／出典}
- 資料2: {タイトル／出典}
- 資料3: {タイトル／出典}

## 共通して見えてくるパターン
1. {パターン1}（根拠：資料1・資料3）
2. {パターン2}（根拠：資料2）

## 資料間で食い違っている点
- {論点}について、資料1は◯◯と言う一方、資料2は◯◯としている

## ここから言える示唆（インサイト）
- {示唆1}：だからこう考えられる／こう動くとよさそう
- {示唆2}：◯◯

## 次のアクション案
1. {具体的な次の一手}
2. {具体的な次の一手}
```

## 検証チェックリスト
```
□ 「要約」で終わらず、「だから何が言えるか」まで踏み込めているか
□ 各パターン・示唆に、どの資料が根拠かを明記しているか
□ 資料同士が矛盾している場合、それを隠さず両論併記しているか
□ 資料の量が多い場合、重要度の低い情報を削って本質だけ残せているか
□ 専門用語は平易な言葉に言い換えているか
□ 次のアクションが具体的で、人事担当者がそのまま動ける内容になっているか
```

## 終了条件
共通パターン・矛盾点・示唆・次のアクション案を提示したら一区切りとする。追加の資料や深掘りしたい論点があればユーザーからの指示を待つ。
