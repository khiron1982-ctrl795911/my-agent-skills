# /knowledge-structuring-skill — メモ・議事録の構造化スキル

## 使い方
```
/knowledge-structuring-skill この会議メモを議題ごとに整理して
/knowledge-structuring-skill 面談で聞いた内容を構造化してほしい
/knowledge-structuring-skill バラバラなメモを、いつ・誰が・何をするかで整理して
/knowledge-structuring-skill この内容を階層構造（大項目→中項目→小項目）にまとめて
```

## このスキルがやること
1. 入力された雑多なメモ・議事録・ヒアリング内容を通読し、話題ごとの塊を見つける
2. 大項目（テーマ）→中項目（論点）→小項目（詳細・発言）の階層に分ける
3. 内容の性質に応じて適切な型（例：課題／原因／対策、決定事項／保留事項／宿題、5W1H等）を選んで当てはめる
4. 重複している内容をまとめ、話が飛んでいる部分は文脈が分かるように補足する
5. 「決まったこと」「決まっていないこと（要検討）」「誰が何をいつまでにやるか（アクション）」を明確に分離する
6. 下記フォーマットで階層構造として出力する

## 出力フォーマット
```markdown
# {テーマ／会議名など}

## 1. {大項目1}
- 概要: {何についての話か、一言で}
  - {中項目1-1}: {内容・発言の要点}
  - {中項目1-2}: {内容・発言の要点}

## 2. {大項目2}
  - {中項目2-1}: {内容}

## 決まったこと
- {決定事項1}
- {決定事項2}

## まだ決まっていないこと（要検討）
- {保留事項1}

## アクション（誰が・何を・いつまでに）
| 担当   | やること       | 期限     |
|--------|----------------|----------|
| {氏名} | {タスク内容}   | {日付}   |
```

## 検証チェックリスト
```
□ 元のメモにある情報を勝手に削らず、階層に振り分けられているか
□ 大項目・中項目の粒度が揃っているか（大きさがバラバラでないか）
□ 「決定事項」「要検討」「アクション」が混ざらず分離されているか
□ アクション項目には担当者・期限が（分かる範囲で）入っているか
□ 専門用語やフレームワーク名には平易な説明を添えているか
□ 元の発言者の意図を変えずにまとめられているか
```

## 終了条件
階層構造・決定事項・アクション一覧を提示したら一区切りとする。追加の整理軸や修正指示があればユーザーからの指示を待つ。
