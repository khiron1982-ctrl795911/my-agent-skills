# /long-video-draft — 台本〜下書き投入ワンストップ

アプリ: `C:\Users\khiro\projects\long-video-studio\`（画面: http://127.0.0.1:8710）

## 手順（必ずこの順で全部やる）

### 1. テーマ確認と事実確認
- テーマ未指定なら確認する。「話題のゴシップ」系なら先に /gossip-scout の手順でリサーチ
- 実在の人物・出来事を扱う場合は WebSearch/WebFetch で事実確認する（日付・固有名詞・数字）
- 公式発表は断定、週刊誌情報は「〜と報じられました」「〜と言われています」と書き分ける

### 2. 台本作成（アプリの記法）
- 空行でシーン区切り、各シーンの1行目が見出し、2行目以降がナレーション
- 見出し先頭: `✗`=注意(赤) / `✓`=対策・ポイント(緑) / `■まとめ`=まとめ画面（`・`行がカード）
- `★`で始まる行=強調ポイント（読み上げ対象外）
- 最初のシーンは自動でオープニング。冒頭にフック、最後にCTA（高評価・チャンネル登録）
- 尺の目安: **10分=3,800〜4,200文字**（14〜16シーン）／**20分=7,000〜8,500文字**（20〜28シーン）
- `scripts/テーマ名_台本.txt` に UTF-8 で保存

### 3. 下書き投入＋サムネイル生成
```
cd ~/projects/long-video-studio
python -X utf8 draft_tool.py set --title "タイトル" --subtitle "サブタイトル" \
    --color pink --speaker 8 --speed 1.0 --hashtags "タグ1, タグ2, ..." \
    --script-file "scripts/テーマ名_台本.txt"
```
- 出力されるシーン数・推定分数を確認し、目標尺から大きく外れていたら台本を調整して再実行
- 色の目安: エンタメ=pink / ビジネス=blue / IT=cyan / 学習=green / AI=purple
- 話者の目安: 2=ずんだもん(元気) / 8=春日部つむぎ(やさしい) / 13=青山龍星(男性・落ち着き)
- 生成されたサムネイル `drafts/thumbnail.png` を Read で目視確認する

### 4. サーバー起動＋ブラウザで開く
- `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8710/` が 200 でなければ:
  `cd ~/projects/long-video-studio && python -c "import app; app.app.run(host='127.0.0.1', port=8710)"` を run_in_background で起動
- PowerShell で `Start-Process "http://127.0.0.1:8710"` を実行してユーザーのブラウザで開く

### 5. 報告
- フォームは全項目入力済み・サムネイル生成済みであること、
  あとは「台本をチェックする」→「この内容で動画を作る」を押すだけであることを伝える
- サムネイルを作り直したい場合は /thumbnail-remake（「サムネイル作り直して」）と案内する
- 動画生成時は下書きのサムネイルがそのまま使われる（作り直したものも反映される）

## 安全ルール
- 実在人物のネタは確定報道ベースで書く。誹謗中傷・断定的な憶測は書かない
- 自死などセンシティブな内容を含む場合は抑えた表現にし、概要欄への相談窓口記載を提案する
- 動画生成・YouTubeアップロードのボタンは押さない（ユーザーが押す）
