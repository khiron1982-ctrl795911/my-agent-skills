# Downloads 月次クリーンアップ

対象: `C:\Users\kuwata\Downloads`

## 原則

- **削除はしない。移動のみ**（削除候補はリスト化してユーザー承認後に削除）
- 移動は Python (`os` / `shutil`) で行う（日本語ファイル名の文字化け防止）
- 同名ファイルが移動先にある場合は上書きせず `_2` 等を付ける
- 分類に迷うファイル（判定ルールに一致しないが機微に見えるもの等）は動かさず報告する

## 分類ルールと移動先

| 分類 | 判定 | 移動先 |
|---|---|---|
| インストーラ | `*.exe` `*.msi`、ツール配布zip・展開済みツールフォルダ（node-*, uv-*, 等） | `C:\Users\kuwata\work\_archive\installers\` |
| 重複DL | ` (N)` 付きで同名の元ファイルが存在 | `C:\Users\kuwata\work\_archive\duplicates\` |
| 給与・人事の機微データ | ファイル名に次のキーワードを**含む**（前方一致でなく部分一致）: 給与 / 賞与 / 勤怠 / 業績評価 / コンピテンシー評価 / 評価 / 人員 / 名簿 / 履歴書 / 経歴書 / レジュメ / スキルシート / 面談 / グレード / 源泉 / 支給控除 / 算定 / 月変 / 雇用契約 / 内定 / 採用通知 / 入社書類 / 出向 / マイナンバー / 基本情報 / 所属情報 / Evaluation_ / resume / CV | `C:\Users\kuwata\Desktop\人事フォルダ\1.個人フォルダ\99.Downloads退避\` |
| その他 | 上記以外 | 触らない（ユーザーの作業ファイルの可能性） |

## 手順

1. **ドライラン**: Downloads を一覧し、上記ルールで分類。移動は実行せず
   「分類別の件数＋代表例＋移動先」を表で報告してユーザーの承認を得る。
2. 承認後、Python スクリプト（`work\_archive\cleanup-logs\` にスクリプトとログを置く）で
   移動を実行し、移動ログ（元→先の全件、実行日時付き）を
   `work\_archive\cleanup-logs\cleanup_YYYYMMDD.txt` に保存する。
3. 実行結果を報告: 移動件数 / スキップ件数（同名リネーム含む）/ 触らなかった残件数。
4. `99.Downloads退避\` に溜まったものは四半期ごとにユーザーへ「正式な保管場所への移動」を提案。
5. `_archive\installers\` の90日超ファイルは削除候補としてリスト提示（承認後に削除）。
