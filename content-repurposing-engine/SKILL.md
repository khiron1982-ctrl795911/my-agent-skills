# /content-repurposing-engine — コンテンツ使い回し展開スキル

## 使い方
```
/content-repurposing-engine                          # 直前の会話・貼り付けた文章を複数形式に展開
/content-repurposing-engine ブログ記事.txt を要約とメルマガ文に  # 元ネタと展開先を指定
/content-repurposing-engine この議事録を社内共有メモと箇条書きにして
/content-repurposing-engine 3形式（要約/Q&A/チェックリスト）で展開して
```

## このスキルがやること
1. 元コンテンツ（貼り付けテキスト・ファイル・直前の会話内容）を読み込み、主張・結論・根拠を整理する
2. 指定がなければ「要約」「箇条書き」「Q&A形式」「社内共有メモ」など、用途の異なる2〜3形式を提案する
3. 元の主旨・数字・固有名詞を変えずに、それぞれの形式に合わせて文章を再構成する
4. 各形式ごとに文字数・読みやすさを調整する（冗長な言い回しを削る）
5. SNS投稿（Threads/Instagram）そのものが必要そうな場合は、生成せずに「/sns-threads」「/sns-instagram」の利用を案内する
6. 完成した複数形式をまとめて画面に出力する（ファイル保存はユーザーが指定した場合のみ）

## 出力フォーマット
```markdown
# コンテンツ展開結果

## 元ネタの要点
- {主張1}
- {主張2}
- {結論}

## 形式1: {形式名（例：3行要約）}
{本文}

## 形式2: {形式名（例：箇条書きメモ）}
- {項目1}
- {項目2}

## 形式3: {形式名（例：社内共有文）}
{本文}

---
展開元の文字数: {N}文字 → 各形式の文字数: {N1}/{N2}/{N3}文字
[下書き - 要確認]
```

## 検証チェックリスト
```
□ 元コンテンツの主張・数字・固有名詞を変えていないか
□ 各形式が用途に合った長さ・トーンになっているか
□ 冗長な繰り返し表現を削れているか
□ SNS投稿そのものを求められた場合、専用スキルへの案内を出したか
□ 「[下書き - 要確認]」を末尾に付けたか
```

## 終了条件
指定した形式（未指定時は2〜3形式）の展開結果を画面に出力したら止まる。
「◯形式に展開しました。内容を確認してください。SNS投稿として使う場合は /sns-threads か /sns-instagram をお使いください」と報告する。
