# /long-form-summary-compressor — 長文要約スキル

## 使い方
```
/long-form-summary-compressor この資料を3行で要約して
/long-form-summary-compressor この記事を要約して、箇条書き5個以内にして
/long-form-summary-compressor 長いメールの内容を一言でまとめて
/long-form-summary-compressor この議事録を要点だけ短くして
```

## このスキルがやること
1. 対象の長文（記事・資料・メール・議事録など）を通読する
2. 主張・結論・重要な数字など「これがないと意味が変わる」情報を洗い出す
3. 前置き・重複表現・具体例の繰り返しなど、なくても意味が通じる部分を削る
4. 指定された長さ（行数・文字数・箇条書きの数）に収まるよう圧縮する
5. 元の文章のニュアンス（賛成／反対、断定／推測など）を変えずに短くする
6. 指定がなければ「3行要約＋詳細箇条書き」の2段階で出力する

## 出力フォーマット
```markdown
## 3行要約
1. {結論・最も重要な点}
2. {次に重要な点}
3. {背景または注意点}

## もう少し詳しく（箇条書き）
- {要点1}
- {要点2}
- {要点3}

（元の文字数: 約{N}文字 → 要約後: 約{M}文字）
```

## 検証チェックリスト
```
□ 指定された長さ（行数・文字数・箇条書き数）を守っているか
□ 削った部分に、結論を左右する重要情報が含まれていないか
□ 元の文章の立場・トーン（賛成/反対、断定/推測）を変えていないか
□ 同じ内容を違う言葉で繰り返していないか
□ 専門用語をそのまま残さず、平易な言葉に言い換えているか
□ 箇条書き・階層など「整理」に寄りすぎず、あくまで短くすることを優先しているか
```

## 終了条件
指定された形式・長さで要約を提示したら一区切りとする。文字数調整や再要約の依頼があればユーザーからの指示を待つ。
