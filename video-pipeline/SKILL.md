# 動画パイプライン スキル

## このスキルでできること

テーマとナレーション文を渡すだけで以下を全自動生成する：

- `output/final_video.mp4` — 完成動画
- `output/thumbnail.png` — YouTubeサムネイル（1280×720）
- `output/description.txt` — 説明文＋ハッシュタグ（1行ずつ）
- `output/images/` — 各シーンのイラスト（Pillowで自動生成）
- `output/audio/` — 各シーンの音声（VOICEVOX）

---

## ワークフロー

### STEP 1 — ユーザーから情報を引き出す

以下を会話から読み取る（足りなければ質問する）：

| 項目 | 説明 | デフォルト |
|------|------|------|
| `title` | 動画タイトル | （必須） |
| `subtitle` | サブタイトル | titleを短くしたもの |
| `color` | テーマカラー | `blue` |
| `speaker` | デフォルト話者ID | `2`（ずんだもん） |
| `hashtags` | ハッシュタグ（リスト） | Claudeが内容から自動生成 |
| `scenes` | シーンのリスト | （必須） |
| `target` | 対象視聴者 | 指定なし |
| `duration` | 目標尺（分） | 指定なし |

### STEP 2 — ハッシュタグを自動生成する

ユーザーが指定しない場合、テーマと対象視聴者から最適なハッシュタグを12個選ぶ。
選定基準：
- テーマに直結するキーワード 4個
- 関連ジャンルのキーワード 4個
- ビジネス・仕事術・効率化など拡散向け 4個

### STEP 3 — make_video.py を生成する

以下のテンプレートに従って `~/projects/video_pipeline/make_video.py` を生成する。

#### テンプレート構造

```python
# ══════════ ここだけ編集する ══════════

THEME = {
    "title":    "{title}",
    "subtitle": "{subtitle}",
    "color":    "{color}",   # pink/cyan/green/yellow/blue/purple
    "speaker":  {speaker},
    "hashtags": [
        {hashtags をリスト形式で1行ずつ},
    ],
}

SCENES = [
    {
        "id": 1, "type": "{scene_type}",
        "speaker": {speaker_id},
        "heading": "{見出し}",
        "text": "{ナレーション文}",
        # typeごとの追加フィールドも含める（下記参照）
    },
    ...
]
```

#### シーンタイプと追加フィールド

| type | 用途 | 追加フィールド |
|------|------|------|
| `intro` | オープニング・タイトル | `sub`, `badge` |
| `mistake` | 悪い例・警告 | `number`, `icon`(✗/⚠), `point`(一言まとめ) |
| `solution` | 解決策・良い例 | `number`, `icon`(✓), `point`(一言まとめ) |
| `summary` | まとめ | `items`(箇条書きリスト) |
| `default` | 汎用 | なし |

#### イラストスタイルの選び方

- `intro` → 青系グラデーション＋幾何学装飾
- `mistake` → 赤/黄警告スタイル（左帯赤、✗アイコン）
- `solution` → 緑解決スタイル（左帯緑、✓アイコン）
- `summary` → カードリスト形式（5項目まで）

### STEP 4 — 実行手順を案内する

生成後、以下を伝える：

```
① VOICEVOXを起動する
② Git Bashで実行：
   cd ~/projects/video_pipeline
   python make_video.py
③ 完成したら：
   explorer output
```

## 重要な注意事項

1. `make_video.py` は `~/projects/video_pipeline/` に置く
2. VOICEVOXはポート `50021` で起動している前提
3. ナレーション文に句読点を適切に入れると音声が自然になる
4. `mistake`/`solution` はペアで使うと動画のリズムが良くなる
5. ハッシュタグは `description.txt` に1行ずつ出力される（コピペ用）

## 【v2.0追加】実行前チェックと典型エラー対処

### 実行前チェック（スクリプト冒頭に必ず組み込む）
```python
import requests, sys
try:
    requests.get("http://localhost:50021/version", timeout=3)
except Exception:
    sys.exit("❌ VOICEVOXが起動していません。VOICEVOXを起動してから再実行してください。")
```

### 典型エラー対処表
| 症状 | 原因 | 対処 |
|---|---|---|
| 音声が無音/短い | 句読点なしの長文 | 1文150字以内に分割、句読点を追加 |
| フォント化け | 日本語フォント未指定 | Pillowで `meiryo.ttc` 等をフルパス指定 |
| moviepy ImportError | v2系の破壊的変更 | `moviepy==1.0.3` 固定を推奨 |
| 音声と画像の数不一致 | シーン定義の欠落 | 生成前に `len(SCENES)` と音声ファイル数を assert |

### 出力後セルフチェック
- [ ] 動画尺が目標±20%以内か（大幅超過ならシーン文字数を見直し）
- [ ] サムネイルのテキストがはみ出していないか
- [ ] description.txt のハッシュタグが12個あるか
