# /sns-x — X投稿下書き生成スキル

## 使い方
```
/sns-x                          # 今日の投稿3本を下書き生成
/sns-x 5                        # 今日の投稿5本を下書き生成
/sns-x テーマ：AI副業の始め方   # テーマ指定で生成
/sns-x --pr                     # アフィリエイトPR投稿を1本生成
```

## このスキルがやること
1. `~/sns/BRAND_GUIDE.md` と `~/sns/CLAUDE.md` を読み込む
2. `~/.claude/projects/C--Users-khiro/memory/feedback_sns.md` のフィードバックを確認
3. 指定本数のX投稿下書きを生成する
4. 各投稿を検証する（文字数・文体・禁止表現・CTA）
5. `~/sns/_drafts/x/YYYY-MM-DD_N.md` に保存する
6. 「下書きを保存しました。確認してください」と報告して止まる

## 生成ルール（必ず守ること）

### フォーマット
- 1投稿: 140文字以内（URLを含む場合はURLを23文字として計算する）
- 長文になる内容は note へのリンク誘導に切り替える（「詳しくはnoteに書きました →」）
- 絵文字: 多用せず1〜2個まで

### 検証チェックリスト（全て◯になるまで修正する）
```
□ 文字数が140文字以内か（URLは23文字換算で必ず自分でカウントする）
□ BRAND_GUIDE.md の文体・一人称と合っているか
□ 禁止表現（「絶対」「100%」「必ず稼げる」等）が含まれていないか
□ CTAが入っているか（BRAND_GUIDE.md のX用CTAから選ぶ）
□ 「[下書き - 要確認]」が末尾に付いているか
□ （PR投稿のみ）「#PR」が冒頭付近にあるか
□ （PR投稿のみ）`{楽天リンクをここに貼る}` プレースホルダがあるか
□ （PR投稿のみ）効果の断定ではなく実体験ベースの表現になっているか
```

### 保存フォーマット（Markdownファイル）
```markdown
# X下書き — {YYYY-MM-DD} #{N}

{投稿テキスト本文}

---
文字数: {N}文字（URL23文字換算込み）
テーマ: {テーマ}
CTA: {使用したCTA}
生成日時: {YYYY-MM-DD HH:MM}

[下書き - 要確認]
```

## アフィリエイトPR投稿（--pr または自動混在）
- ルールの原本は `~/sns/AFFILIATE.md`。生成前に必ず読むこと
- **週の上限は Threads・X 合算で2本まで**（`~/sns/_drafts/threads/` と `~/sns/_drafts/x/` の直近7日の `_PR` ファイルを両方数える）。合算ですでに2本あれば混ぜない
- PR投稿の追加ルール:
  - 冒頭付近に「#PR」を必ず入れる（ステマ規制対応。省略・末尾隠しは不可）
  - 商品は AFFILIATE.md のジャンル内から選び、「実際に使ってみた／読んでみた」体験談の型で書く
  - 140文字制限が厳しいため、詳細は書かず「1件目のコメントを見てもらう」または note 誘導にする
  - 本文にはリンクを直接書かず `{楽天リンクをここに貼る}` プレースホルダを置く（本文に貼る場合は23文字としてカウントする）
  - ファイル名は `YYYY-MM-DD_N_PR.md` とする

## /loop との組み合わせ方
```
/loop 今日のX投稿3本を/sns-xで下書き生成して_drafts/x/に保存されたら止まって
```

## 終了条件
指定本数のファイルが `~/sns/_drafts/x/` に保存されたら必ず止まる。
「〇本の下書きを保存しました。`sns/_drafts/x/` を確認してください。」と報告する。

## 投稿について
投稿の実行（公開）は必ず本人が行う。このスキルは下書き保存までで、Xへの自動投稿は行わない。
