# /competitive-intelligence-skill — 比較・競合分析スキル

## 使い方
```
/competitive-intelligence-skill 人事評価ツールA と 人事評価ツールB を比較して
/competitive-intelligence-skill 勤怠管理システムを3社（A社・B社・C社）で比較表にして
/competitive-intelligence-skill このツールのSWOT分析をして
/competitive-intelligence-skill 導入候補の中でどれが自社（従業員100名規模）に合うか教えて
```

## このスキルがやること
1. 比較対象（製品・サービス・ツール）を整理し、比較軸（価格、機能、サポート体制、導入のしやすさ等）を決める
2. 各対象について、公開情報や提示された資料から特徴を洗い出す
3. 比較表を作成する（下記フォーマットに従う）
4. 対象ごと、または全体としてSWOT分析（強み・弱み・機会・脅威）を行う
5. 利用シーン（従業員規模、予算、優先したいポイント）を踏まえた推奨案を1〜2文でまとめる
6. 断定的な結論ではなく「判断材料」として提示する（最終判断はユーザーが行う旨を明記）

## 出力フォーマット

### 比較表
```markdown
| 比較軸       | 製品A            | 製品B            | 製品C            |
|--------------|-------------------|-------------------|-------------------|
| 料金の目安   | 月額◯円〜        | 月額◯円〜        | 月額◯円〜        |
| 主な機能     | ◯◯、◯◯          | ◯◯、◯◯          | ◯◯、◯◯          |
| 導入のしやすさ | 易／普通／難    | 易／普通／難      | 易／普通／難      |
| サポート体制 | ◯◯               | ◯◯               | ◯◯               |
| 向いている会社 | 例：小規模向け  | 例：中堅企業向け  | 例：大企業向け    |
```

### SWOT分析
```markdown
## {対象名} のSWOT分析
- 強み（Strengths）: ・◯◯
- 弱み（Weaknesses）: ・◯◯
- 機会（Opportunities）: ・◯◯
- 脅威（Threats）: ・◯◯

## まとめ・おすすめの考え方
{どんな条件（規模・予算・優先事項）ならどれが向いているか、1〜2文で}
```

## 検証チェックリスト
```
□ 比較軸が全対象で揃っているか（片方だけ項目が抜けていないか）
□ 数字や機能名など事実にあたる部分は、根拠（出典）を示せる状態か
□ 良い面・悪い面の両方をフラットに書けているか（一方に偏っていないか）
□ 専門用語に平易な説明を添えているか
□ 「最終判断は自社の状況に応じてご検討ください」等、断定を避ける一文が入っているか
```

## 終了条件
比較表とSWOT分析（または簡易まとめ）を提示したら一区切りとする。追加の比較軸や対象があればユーザーからの指示を待つ。
