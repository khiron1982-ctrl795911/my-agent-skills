# Codex Bridge — Claude ⇔ Codex 連携プロトコル

## 役割分担（固定）

| 担当 | Claude | Codex |
|---|---|---|
| 得意領域 | 要件定義・日本語文書・HR業務文脈・スキル設計 | リポジトリ全体走査・実行検証・修正PR作成 |
| 主タスク | HANDOFF.md生成 / REVIEW.md取り込み / 修正方針判断 | コードレビュー / セキュリティ監査 / テスト実行 |
| 最終判断 | **HIRO**（両AIの指摘が矛盾したらClaudeが論点整理して提示） | — |

## 連携フロー（往復1サイクル）

```
[Claude] HANDOFF.md 生成
   ↓ HIROがCodexに貼り付け（またはリポジトリに置いて「HANDOFF.mdを読んで実行」）
[Codex]  レビュー/監査を実行 → REVIEW.md 形式で出力
   ↓ HIROがREVIEW.mdをClaudeに貼り付け/アップロード
[Claude] 指摘を重要度順に整理 → 採用/棄却の推奨 → 修正版コード or スキル改訂を生成
```

## HANDOFF.md テンプレート（Claudeが生成する）

```markdown
# HANDOFF — {タスク名} / {日付}
## Context
- 依頼者環境: Windows / Git Bash / Python 3.x
- 対象: {ファイルパス or 貼り付けコード}
- このコードの目的: {1-2行。給与データ処理なら「個人情報を含む」と明記}
## Task
{レビュー観点を箇条書きで指定。下のプリセットから選択}
## Constraints
- 挙動を変える修正は提案のみ（勝手に書き換えない）
- 外部ライブラリ追加は理由付きで提案
## Output format
REVIEW.md 形式（下記）で出力すること。日本語で。
## REVIEW.md 形式
| # | 重要度(Critical/High/Med/Low) | ファイル:行 | 指摘 | 修正案 |
最後に「総合評価」と「修正しない場合のリスク」を記載。
```

## レビュー観点プリセット

### A. 通常コードレビュー
例外処理の網羅 / パスのハードコード / マジックナンバー / 冪等性 / ログ出力

### B. セキュリティ監査（給与・人事データ用 — 最重要）
1. **秘密情報**: ハードコードされたAPIキー・パスワード・トークン（git履歴含む）
2. **個人情報の漏洩経路**: 給与・社員データがログ/一時ファイル/クラウド同期フォルダ（OneDrive配下）に平文で残らないか
3. **入力検証**: Excelファイル名・シート名のパスインジェクション、`eval`/`exec`/`os.system`の使用
4. **依存関係**: `pip list` の既知脆弱性（`pip-audit` 実行を指示）、バージョン未固定
5. **出力先**: 成果物の保存先が意図した場所か、権限は適切か
6. **ネットワーク**: localhost以外への送信がないか（VOICEVOXは50021のみ許可）

### C. スキルレビュー（SKILL.md用）
指示の曖昧さ / 前提条件の明示漏れ / トリガーキーワードの過不足 / 500行超過

## REVIEW.md 取り込み時のClaudeの動作

1. Critical/High を先に列挙し、**各指摘に採用/保留/棄却の推奨と理由**を付ける
2. Codexの指摘を鵜呑みにしない：HR業務文脈（例：全角ファイル名は業務上必須）と
   矛盾する指摘は棄却理由を明記
3. 採用分の修正コードを生成し、該当スキルのCHANGELOGにも反映（skill-improver連携）

## セキュリティ監査の定期運用（推奨）

| 頻度 | 対象 | 使うプロンプト |
|---|---|---|
| 月次 | 給与系スクリプト（kintai_kyuyo_check.py 等） | codex-prompts/01_security_audit.md |
| リリース時 | 新規/大改修スクリプト | 01 + 02 |
| 四半期 | 全スキルのSKILL.md | codex-prompts/03_skill_review.md |

## 注意（正直な制約）

- Claude↔Codexの**自動連携APIは存在しない**。本プロトコルはファイル/コピペ経由
- 監査結果はAIレビューであり、J-SOX等の正式監査の代替にはならない。統制文書に
  使う場合は「AI支援による自主点検」と位置づけ、最終確認は人間が行うこと
