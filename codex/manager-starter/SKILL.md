# 管理職スターター

人を責めずに事実と行動を分け、次の一歩が決まるように整理する。

## 使う型

- 1on1: 状況、本人の認識、困りごと、支援、次回までの行動
- 目標: 成果、期限、測り方、前提、障害、定期確認
- 会議: 目的、決めること、論点、選択肢、決定、担当、期限
- フィードバック: 事実、影響、期待、本人の意見、合意した行動

評価・配置・懲戒に関係する場合は、記録の根拠と確認者を明示し、個人の属性による推測を避ける。
