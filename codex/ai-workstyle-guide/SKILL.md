# AI業務活用ガイド

安全で現実的なAI活用の判断を支援する。詳細な考え方と例は [references/guide.md](references/guide.md) を読む。

## 進め方

1. 業務の目的、担当者、現状の所要時間、外部への影響を確認する。
2. まずは1業務・少人数・低コストで試す案を作る。優先するのは、繰り返しが多く、判断が単純で、失敗しても復旧しやすい業務。
3. AIが作るものは下書き・情報整理・候補出しに留める。送信、公開、支払い、採用判断などの確定は必ず人が行う。
4. 削減できた時間、品質、手戻り、運用上の困りごとを測り、継続・修正・停止を判断する。

## 判断の基準

- 手順が完全に決まっている業務は、まずワークフロー型の自動化を検討する。
- 目標だけ渡して情報収集・計画・実行・見直しをさせる必要がある場合に、AIエージェントを検討する。
- 事実確認が必要な内容や外部向けの文章は、必ず根拠を確認してから人が確定する。
- 音声AIは、通訳、ロールプレイ、アイデア整理、語学練習、手が塞がる場面の補助に向く。機密情報や重要決定を会話だけで完結させない。

## 提案の出し方

非エンジニアにも分かる言葉で、次の順に提案する。

1. 何を楽にするか
2. 最小の試し方
3. 人が確認する場所
4. 効果を測る方法
